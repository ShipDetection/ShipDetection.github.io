Ship Detections Webmap

The Ship Detections Webmap is a tool that allows users to view the locations of ships, oil rigs, and wind farms at sea. It uses satellite imagery and other data sources to plot the locations of these objects on an interactive map. The webmap also provides detailed information about each object, such as its size and the date of the detection. Currently the main site relies on vector tiles which prevents this information from being transmitted however this is an area of active development.

The Ship Detections Webmap is designed to be a useful tool for shipping companies, offshore energy operators, and other organizations that need to track the locations of objects at sea. It is also a valuable resource for researchers and others interested in studying the distribution of ocean objects.

Methodology

The Ship Detections Webmap program uses Sentinel-1 satellite imagery from the Alaska Satellite Facility to detect and track ships at sea. The Sentinel-1 constellation is a fleet of radar imaging satellites operated by the European Space Agency (ESA) for the Copernicus Earth observation program. To download Sentinel-1 imagery from the ASF, the Ship Detections Webmap program uses the ASF's API to search the data catalog and select the desired imagery. The program then uses the API to download the selected Sentinel-1 data. Once the Sentinel-1 imagery is downloaded, the Ship Detections Webmap program uses the ESA's Sentinel Application Platform (SNAP) and its Graph Processing Tool (GPT) module to extract the ship locations from the radar images. GPT uses advanced algorithms and techniques to identify and plot the positions of ships on the interactive map. Overall, the Ship Detections Webmap program combines the capabilities of Sentinel-1 satellite imagery, the ASF API, SNAP GPT, and other data sources to accurately track ships at sea and provide valuable information to shipping companies and other organizations.
